Guitar GAPS checkpoint and reference inference

Checkpoint publisher: Xavier Riley and contributors.
https://huggingface.co/xavriley/midi-transcription-models
Revision b7bec65a2b860aca72856b0feef58b5df407b777, guitar-gaps.pth.
The publisher's model card declares MIT. See also GAPS: A Large and Diverse
Classical Guitar Dataset and Benchmark Transcription Model, Riley, Guo,
Edwards and Dixon, ISMIR 2024, https://arxiv.org/abs/2408.08653.

Reference code: Xavier Riley, hf_midi_transcription (README declares MIT),
and Qiuqiang Kong, piano-transcription-inference (PyPI MIT classifier).
https://github.com/xavriley/hf_midi_transcription
https://github.com/xavriley/piano_transcription_inference
https://pypi.org/project/piano-transcription-inference/

Apophenia modifications: exported the neural backend to ONNX, quantised
MatMul/Gemm weights to int8 and stored GRU weights as FP16 with explicit
FP32 computation. A separate mel matrix and Kotlin frontend, window joining
and regression decoder implement the published inference algorithm.
No automatic instrument selection. Models and processing run offline.
