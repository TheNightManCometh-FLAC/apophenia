# M7 walkthrough — Exports and release

Phone: Samsung Galaxy S22 Ultra (SM-S908U), Android 16.

## 1. MusicXML export (build 0.7.0)
1. Open a tab scrap (or make one: a few notes on the guitar, a chord symbol, a tied note, a triplet).
2. ⋯ › MusicXML. The save picker opens with the scrap's title and `.musicxml`; save it to Downloads. A notice says "MusicXML file saved."
3. On the PC: open it in MuseScore 4 (free). Check: notation on a treble-8vb clef and tab under it with the same frets; the tied note, the triplet bracket, the chord symbol above.
4. A sheet-music scrap with lyrics and a 1st/2nd ending: the same in MuseScore, lyrics hyphenated, endings in place.
5. Cancel the save picker once: nothing is written, no notice.

## 2. MIDI, text tab, ChordPro (build 0.7.1)
1. The same tab scrap › ⋯ › MIDI: save, open in FL Studio (drag into the playlist or File › Import › MIDI): one track a part, the tempo right, a 7/8 or 6/8 meter shown right; tied notes are single notes; a repeat plays out.
2. ⋯ › Text tab: the .txt opens in any editor; six string lines a system, frets in place.
3. A lyric scrap › ⋯ › Export ChordPro: `{title}` and `{key}` at the top, chords in brackets.
4. A chord chart › ⋯ › Export ChordPro: one grid per section, `.` on held beats.

## 3. Licences and privacy (build 0.7.2)
1. LIBRARY ⋯ › Licences and privacy: the PRIVACY paragraph, then 14 rows.
2. Tap Signalsmith Stretch: its MIT text opens under it; tap again to close.
3. Tap LiteRT: its licence, then the third-party notices' first part with a note on where the rest is. Scrolling stays smooth.
4. Back (‹ or the system back) returns to the Library.

## 4. BAM splash (build 0.7.3)
1. Swipe Apophenia out of recents, then open it from the launcher: the launcher icon on black (Android's own splash), then the Better App Mafia mark fades in, holds about a second and a half, and fades out to the Board. No white flash at any point.
2. Open it cold again and tap the mark: it fades out at once.
3. Rotate the phone, or leave the app and come back: no splash.
4. Use the Record widget with the app closed: no splash; the recording screen shows straight away.

## 5. MusicXML import (build 0.7.4)
1. Export a tab scrap as MusicXML (§1), then LIBRARY › import that file: a tab scrap with the same title opens, notes and frets as before.
2. From MuseScore 4 on the PC: File › Export › MusicXML (both .mxl and uncompressed). Copy both to the phone and import them. A piano piece comes in as two parts (upper, lower); a guitar piece with tab comes in as one tab part with the right tuning.
3. Import a .xml that isn't music (any other XML file): "Not imported: It isn't a MusicXML score."
4. The import notice lists anything a file was read without (slurs, hairpins).

## 6. MIDI import (build 0.7.5)
1. Export a tab or sheet scrap as MIDI (§2), then LIBRARY › import it: the same notes come back (repeats written out); a guitar or bass part comes back as tab.
2. From FL Studio: export a pattern with drums, bass (a bass plugin on program 34) and keys as MIDI (File › Export › MIDI file), copy it to the phone and import it. One part per channel; the drums in their own part; the playing snapped to sixteenths; a triplet fill written as triplets.
3. Open the imported scrap in the piano roll: notes where FL Studio had them, to the sixteenth.
